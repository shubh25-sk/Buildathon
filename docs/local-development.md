# Local Development Guide

## Prerequisites
- Node.js v18+ or v20+
- npm v9+

## Quick Start Commands

```bash
# 1. Install workspace dependencies
npm install

# 2. Run React Client (http://localhost:3000)
npm run dev

# 3. Run Express REST Server (http://localhost:4000) in parallel
npm run dev:server

# 4. Execute Vitest Unit & Integration Tests
npm run test

# 5. Execute TypeScript Type checking
npm run typecheck
```
